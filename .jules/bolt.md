## 2025-02-28 - Extract Static Object References for Components
**Learning:** In React applications utilizing `react-markdown` (or similar libraries that take complex objects as props), passing an inline object for the `components` prop causes unnecessary recreation of all those custom render functions on every render of the parent component. A micro-benchmark for this environment showed that static object/function references are ~50-60x faster than inline recreation (e.g., 33ms vs 1.8s for 10M iterations).
**Action:** Always extract static object references, such as the `components` object for `react-markdown`, outside the component body. When doing so with `react-markdown`, explicitly import and apply the `Components` type from `react-markdown` to ensure proper typing.
