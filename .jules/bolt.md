## 2025-05-18 - Extract ReactMarkdown components to prevent re-renders
**Learning:** Defining custom React components inline (e.g., inside `components={{...}}` of a `<ReactMarkdown>` component) forces React to unmount and remount these components entirely on every render of the parent component. This happens because inline definitions recreate function references, causing React to treat them as brand new components in the virtual DOM tree, completely trashing state and destroying performance.
**Action:** Always define objects or functions passed as static configuration (like the `components` map for `react-markdown`) outside of the main component rendering body when they do not depend on component state or props, to leverage static object references and avoid needless re-renders.
