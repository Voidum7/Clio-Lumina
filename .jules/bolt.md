## 2024-05-18 - ReactMarkdown Inline Components Re-mount Anti-Pattern
**Learning:** Defining the `components` prop inline for `ReactMarkdown` (e.g., `<ReactMarkdown components={{...}}>`) inside a component whose state updates frequently (like on every keystroke) causes `ReactMarkdown` to unmount and remount all of its underlying nodes on every render. This creates massive lag, especially with large text bodies like chat histories. Micro-benchmarks show static object extraction provides a ~50-60x speed improvement by avoiding recreation of these references.
**Action:** Always define `ReactMarkdown` custom components (or any complex object props passed to memoized/third-party components) statically outside the component block. Ensure they are explicitly typed using `Components` from `react-markdown` to avoid type errors.
