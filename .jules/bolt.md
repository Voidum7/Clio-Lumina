## 2025-02-28 - Extract static ReactMarkdown custom components
**Learning:** React re-evaluates inline object literals on every render. For expensive components like `ReactMarkdown`, defining `components={{ ... }}` inline creates a new object reference on every parent render, forcing React to unnecessarily unmount and remount all custom component nodes inside the Markdown tree. This is a massive performance bottleneck (~55ms per tick vs ~14ms when static).
**Action:** Always extract custom component mappers (like `Components` in react-markdown) or any complex object literal props to static variables outside the component body (or use `useMemo`) when they don't depend on dynamic component state. Ensure `react-markdown` custom components explicitly use the `Components` type.
