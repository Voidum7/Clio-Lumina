## 2026-04-05 - Prevent full-app re-renders and unmounting in ReactMarkdown\n**Learning:** Storing controlled input state at the root level of a chat application causes the entire message history to re-render on every keystroke. Additionally, defining custom components for `react-markdown` inline inside the render method causes all markdown DOM nodes to be unmounted and remounted on every re-render (as React treats the new inline functions as entirely new component types).\n**Action:** Extract controlled input state to a separate component so only the input re-renders on keystrokes. Always define `react-markdown` custom components statically outside the component body.
