## 2025-03-08 - [Extract Static ReactMarkdown Components]
**Learning:** Defining custom component mappings (like those for `ReactMarkdown`) inline within a React component's render function causes React to recreate those definitions on every single render. This forces React to unmount and remount the DOM elements, leading to DOM thrashing, excessive memory allocation, and significant performance degradation, particularly in lists (like message histories). Micro-benchmarks show that inline creation takes ~381ms for 10M iterations compared to ~14ms for static reference.
**Action:** Always define static objects and function mappings outside of the component body, or use `useMemo` if they depend on component state. For custom component mappings like `react-markdown`'s `components` prop, define them statically at the module level and explicitly import the `Components` type for proper typing.
